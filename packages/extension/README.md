# opencode GUI

A rich GUI for [opencode](https://opencode.ai): chat with **image & file
attachments**, **file search**, **`@`-mentions**, and **slash commands** — on top
of the opencode server. Works in VS Code, Cursor, Windsurf, and VSCodium.

Open the **opencode** view in the Activity Bar. The extension auto-spawns
`opencode serve` for the current workspace (configurable via `opencode.serverUrl`
and `opencode.binaryPath`).

See the [repository](https://github.com/) for development docs.
